# กราฟเปรียบเทียบข้อมูลตรวจอากาศชั้นบน 00Z ปี 2026

เว็บแสดงแดชบอร์ดค่าล่าสุดและกราฟรายดัชนีของสถานีตาคลีกับร้องกวาง กราฟใช้วันตรวจเป็นแกนนอน และเลือกสถานีเพื่อดูกราฟแยกกัน

## ชุดข้อมูล

- ตาคลี: 115 วันตรวจ
- ร้องกวาง: 86 วันตรวจ (29 มกราคม–26 พฤษภาคม 2026)
- ดัชนี: 50 MB Lifted Index, Showalter Index, K Index, SWEAT Index และ Precipitable Water TOTAL
- กราฟเพิ่มเติม: Mean RH 4 ชั้น (1,000–5,000, 5,000–10,000, 10,000–15,000 และ 20,000–25,000 ฟุต) เลือกเปิด/ปิดเส้นแต่ละชั้นได้ และ Wind Rose ใช้ Mean Wind Direction กับ Mean Wind Speed ระหว่าง 5,000–10,000 ฟุต
- ค่าลมและความชื้นช่วง 5,000–10,000 ฟุตอ่านจากไฟล์ `.00Z` ครบทั้งสองสถานี
- ค่า Precipitable Water ของร้องกวางอ่านจากบรรทัด `TOTAL` ในไฟล์ `.00Z` ได้ครบ 86 วัน หน่วยเซนติเมตร
- Wind Rose แบ่งทิศ 16 ช่อง และซ้อนสีตามช่วงความเร็วลม แสดงความถี่เป็นเปอร์เซ็นต์ จำนวนข้อมูล และลมสงบ (ต่ำกว่า 0.5 m/s)
- กราฟเลือกดัชนีและเลือกสถานีแยกกัน เพื่อดูข้อมูลทีละสถานีโดยไม่ให้เส้นทับกัน
- `data.json` เป็นข้อมูลที่อ่านและดาวน์โหลดได้ ส่วน `data.js` เป็นข้อมูลชุดเดียวกันสำหรับหน้าเว็บ

## อัปเดตเว็บบน GitHub

1. เปิด repository `Tong2025/takhli-weather-2026-DRRAA` แล้วกด **Add file → Upload files**
2. ลากไฟล์ `index.html`, `data.js`, `data.json` และ `README.md` จากโฟลเดอร์ `github-pages` มาวางในหน้าอัปโหลด (รวม `.nojekyll` ได้ด้วย)
3. รอให้อัปโหลดเสร็จ แล้วกด **Commit changes** เพื่อบันทึกลง branch `main`
4. GitHub Pages จะเผยแพร่เวอร์ชันใหม่ให้อัตโนมัติ รอสักครู่แล้วรีเฟรชหน้าเว็บ หากยังเห็นหน้าเดิมให้กด `Ctrl+F5`

ไฟล์เว็บและข้อมูลต้องอยู่ที่โฟลเดอร์หลักของ repository เดียวกัน โดยตั้งค่า Pages เป็น branch `main` และโฟลเดอร์ `/(root)` ที่ **Settings → Pages**

## เปิดดูในเครื่อง

เปิดหน้าเว็บผ่าน GitHub Pages หรือเว็บเซิร์ฟเวอร์ในเครื่อง โดยวาง `index.html`, `data.js` และ `data.json` ไว้ในโฟลเดอร์เดียวกัน
