# กราฟข้อมูลตรวจอากาศชั้นบนตาคลี 00Z

เว็บกราฟแบบไฟล์สแตติก ไม่ต้องติดตั้งโปรแกรมเสริม ใช้แสดงข้อมูลตรวจอากาศชั้นบนตาคลี ปี 2026 โดยแยกกราฟแต่ละค่าและใช้วันที่ตรวจเป็นแกนนอน

## วิธีเผยแพร่ด้วย GitHub Pages

1. สร้าง repository ใน GitHub แล้วอัปโหลดไฟล์ในโฟลเดอร์นี้ (`index.html`, `data.js`, `data.json`, `.nojekyll`) ไว้ที่โฟลเดอร์หลักของ repository
2. ใน repository เลือก **Settings → Pages**
3. ที่ **Build and deployment** เลือก **Deploy from a branch** แล้วเลือก branch `main` และโฟลเดอร์ `/(root)` จากนั้นกดบันทึก
4. เปิด URL ของ Pages ที่แสดงใน Settings หลัง GitHub เผยแพร่เว็บเสร็จ

ไฟล์ `index.html`, `data.js` และ `data.json` ต้องอยู่ในโฟลเดอร์เดียวกัน เปิด `index.html` ในเครื่องเพื่อดูได้โดยตรง หรือเผยแพร่ผ่าน GitHub Pages ก็ได้ ไม่ต้องสั่ง build ไม่ต้องติดตั้งแพ็กเกจ และไม่พึ่งไลบรารีกราฟภายนอก

## ข้อมูลในกราฟ

`data.json` รวมข้อมูลจากไฟล์ `.00Z` ที่มีอยู่ 115 วัน เรียงตามวันที่ ประกอบด้วย 50 MB Lifted Index (ค่าเฉลี่ยชั้น 50 MB), Showalter Index, K Index, SWEAT Index และ Precipitable Water TOTAL หน่วยเซนติเมตร วันที่ที่ไม่มีไฟล์ต้นทางจะแสดงเป็นช่องว่างของเส้นกราฟ
